## 成绩构成

- 1次小组合作课堂展示，25分

- 7次课后作业，在线完成，共35分

- 1次期末论文，35分

- 课堂参与度，5分

## 课程经验

没有期末考试，偏水的一门课，但是老师讲得很好，个人感觉还是很有收获的。

每节课前小组展示，第一节课就会分好组抢好选题，小组展示之后叫大家评分。课堂上需要雨课堂答题。课后有智慧树作业题和讨论发帖。只要记得做就问题不大。这里提供了智慧树作业题和我的大作业，仅供参考。
