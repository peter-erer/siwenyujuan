## 一、结合课件与回放整理后的主干 R 代码

```r
# 1. 定义一个包含从 1 到 100 的向量 x
x <- 1:100

# 2. 将向量 x 中的偶数定义成向量 y
y <- x[x %% 2 == 0]

# 3. 将向量 x 中的奇数定义成向量 z
z <- x[x %% 2 == 1]

# 4. 创建一个 50x2 的矩阵 m，包含 y 和 z，并命名列
m <- cbind(y, z)
colnames(m) <- c("Even", "Odd")

# 5. 利用 x 创建一个 10x10 的矩阵 n，并命名行列
n <- matrix(x, nrow = 10, ncol = 10, byrow = TRUE)
colnames(n) <- paste0("C", 1:10)
rownames(n) <- paste0("R", 1:10)

# 6. 创建一个 list，包含 x, y, z, m, n，并输出其中的 matrix_y
list_data <- list(
  vector_x = x,
  vector_y = y,
  vector_z = z,
  matrix_m = m,
  matrix_y = n
)

list_data$matrix_y

# 7. 将 x 中的数分成 A, B, C, D, E 五个等级
grade_fun <- function(v) {
  grade <- character(length(v))

  for (i in seq_along(v)) {
    if (v[i] >= 90) {
      grade[i] <- "A"
    } else if (v[i] >= 80) {
      grade[i] <- "B"
    } else if (v[i] >= 70) {
      grade[i] <- "C"
    } else if (v[i] >= 60) {
      grade[i] <- "D"
    } else {
      grade[i] <- "E"
    }
  }

  grade
}

grade_x <- grade_fun(x)

# 8. 统计 y 中 A, B, C, D, E 的数目
grade_y <- grade_fun(y)
table(factor(grade_y, levels = c("A", "B", "C", "D", "E")))

# 9. 统计 z 中 A, B, C, D, E 的数目
grade_z <- grade_fun(z)
table(factor(grade_z, levels = c("A", "B", "C", "D", "E")))

# 10. 编写函数计算 Ey 和 Ez
# Ey = 1 + y[1]/1! + y[2]^2/2! + y[3]^3/3! + ... + y[50]^50/50!
# Ez 同理
calc_E <- function(v) {
  E <- 1

  for (i in seq_along(v)) {
    E <- E + v[i]^i / factorial(i)
  }

  E
}

Ey <- calc_E(y)
Ez <- calc_E(z)

if (Ey > Ez) {
  print("Ey > Ez")
} else if (Ey < Ez) {
  print("Ey < Ez")
} else {
  print("Ey == Ez")
}

abs(Ey - Ez)
```

## 二、这 10 道题分别在考什么

### 1. `x <- 1:100`

- 考最基本的向量创建。
- 老师强调这类题应该一眼就能写出来。

### 2. `y <- x[x %% 2 == 0]`

- 考：
  - 取模运算 `%%`
  - 逻辑筛选
- 回放里老师专门说：判断偶数，就看“除以 `2` 余数是不是 `0`”。

### 3. `z <- x[x %% 2 == 1]`

- 和上一题同一逻辑。
- 判断奇数，就看“除以 `2` 余数是不是 `1`”。

### 4. `cbind()` 和 `colnames()`

- 考矩阵按列合并。
- 老师在回放里专门点了：
  - `cbind`
  - `colnames`

### 5. `matrix()`、`colnames()`、`rownames()`、`paste0()`

- 这题考的是：
  - 矩阵创建
  - 行列命名
  - 字符串和数字拼接
- 老师提到这里要会用 `paste` 一类函数把 `C` 和数字、`R` 和数字拼起来。

### 6. `list()` 与 `$` 索引

- 考 list 数据结构。
- 需要会：
  - 把不同类型对象放进一个 list
  - 给各元素命名
  - 用 `$` 或 `[[ ]]` 取出指定元素

### 7. `if / else if / else`

- 这是本节最重要的基础控制语句之一。
- 回放末尾老师还专门看了同学的 `else if` 写法，说明这类语法细节容易出错。

### 8-9. `factor()` 与 `table()`

- 这两题不是在考复杂算法，而是在考：
  - 分类结果统计
  - 频数表输出
- 回放里老师明确说：
  - 先把结果变成等级
  - 再用 `table` 自动统计每一类数量

### 10. 自定义函数 + `for` 循环 + `factorial()` + `abs()`

- 这是这节实验课里最综合的一题。
- 主要考：
  - 写函数
  - 设置初始值
  - 循环累加
  - 阶乘 `factorial()`
  - 条件判断比较大小
  - 绝对值 `abs()`

## 三、最后一题的公式和代码思路

课件第 `10` 题的公式是：

```text
Ey = 1 + y[1]/1! + y[2]^2/2! + y[3]^3/3! + ... + y[50]^50/50!
Ez = 1 + z[1]/1! + z[2]^2/2! + z[3]^3/3! + ... + z[50]^50/50!
```

老师在回放里对这题的讲法很明确：

- 先定义一个函数
- 设一个初始值，例如 `E <- 1`
- 用 `for` 循环从 `1` 到 `50`
- 每次把当前项加进去
- 阶乘用 `factorial(i)`
- 最后比较 `Ey` 和 `Ez`
- 再用 `abs()` 求绝对差

可以把这题理解成一个“逐项累加”的经典循环题。

## 六、几处容易写错的地方

### 1. `else if` 语法

- 回放里老师专门看了同学这里的写法。
- 复习时要注意：
  - `if (...) { ... } else if (...) { ... } else { ... }`
- 不要把结构写乱。

### 2. 等级划分区间

- 课件标准是：
  - `A >= 90`
  - `80 <= B < 90`
  - `70 <= C < 80`
  - `60 <= D < 70`
  - `E < 60`
- 所以判断顺序最好从高到低写。

### 3. `table()` 前最好固定 level 顺序

- 如果直接 `table(grade_y)`，有时显示顺序可能不稳定。
- 所以更稳的写法是：

```r
table(factor(grade_y, levels = c("A", "B", "C", "D", "E")))
```

### 4. 第 10 题不要忘记初值 `1`

- 题目不是单纯求和，而是：

```text
E = 1 + ...
```

- 所以初始化不能写成 `0`。
