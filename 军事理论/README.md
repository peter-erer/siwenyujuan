# 军事理论

## 成绩构成
日常考勤：10%
随机点名
请假：≤2次，不扣分；超过2次的扣1分/次
旷课：扣2分/次；超过三次，不允许参加期末考试（北航教学规定）

大作业（二选一）：40%
战例研讨分析（40分）
虚拟仿真实践（40分）

期末考试：50%
闭卷考试
卷面100分，按50%权重计入总成绩

## Tips
课程点名看助教习惯。我们当时是每次两节课间点名，每次点大概10个人左右，一学期下来基本会把大家遍历一遍。

虚拟仿真（俗称“打飞机”）是完成一个驾驶战斗机的仿真游戏。通常总能找到代打服务。

战例研讨很有意思，要求是制作视频之类的，研讨给定选题中的一个，比较有挑战性，但是的确能有所收获。欢迎参考[我们组当时的视频](https://bhpan.buaa.edu.cn/link/AAD060F272A677496EA520DE3BA0598353)。

期末考试几乎完全是老师最后一节课画的重点中的内容，留出1-2天背过就好。
