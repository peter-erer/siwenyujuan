## 🌊 从“三文鱼卷”开始的旅途

“三文鱼卷”是由10系学长创立的微信公众号（[最后一篇招新推送中含有简要介绍](https://mp.weixin.qq.com/s/q_XouH0q9dekRLP-RRbD4g)），曾经是覆盖航类、计类、医工班等学院的学习资源分享平台，帮助过无数伙伴（包括笔者），但是在2024年受不可抗力停止更新。（[最后一篇推送](https://mp.weixin.qq.com/s/eyuAGtSxbU5LPHF02o3x_Q)）我们希望能够把学习与分享的火种传递下去，于是便有了这个仓库——“四文鱼卷”。

它保持三文鱼卷的初心不变，但是转移了阵地。为什么不继续使用微信公众号？因为卑鄙的微信约束，一个身份证只能建立一个个人公众号，而我已经建过了。更重要的是，GitHub 提供了**开放协作、去中心化、开源共享**的天然土壤。这意味着，即使我们这群老登毕业之后，任何小登都可以继续为这个仓库贡献资料，传递下去。

GitHub的维护更新并不复杂，可以理解为就是一个简单的免费云盘，在当前界面就可以像在云盘中一样下载、浏览仓库里的内容。如果为仓库贡献力量，只需要学习简单的 `Pull Request` 操作就可以。关于 git 与 GitHub ，这里推荐[廖雪峰老师的教程](https://liaoxuefeng.com/books/git/)。学会使用 GitHub 进行版本管理、协作、查找开源项目，也是每一位10系学子必要掌握的技能。不如，就从这里开始试试吧！

## 🌐 本地资料站

在仓库根目录运行：

```powershell
.\serve-site.ps1
```

然后访问 `http://127.0.0.1:8000/siwenyujuan/`。如需生成静态网站，运行 `.\build-site.ps1`，输出位于仓库旁的 `siwenyujuan-site` 目录。

## 📜 仓库原则与收录指南

为了维护这片知识花园的纯净与长远发展，我们设立了以下收录原则：

### ✅ 我们欢迎并收集：
- 📝 **考试回忆**：历年真题回忆与期末重点梳理
- 💡 **经验分享**：学习方法、备考经验与心得体会
- 📚 **学习笔记**：优质的个人课堂笔记、总结与思维导图

### 🚫 我们不接受：
- ⚠️ 涉及版权保护的官方教材、原版专著及电子书等
- ⚠️ 未经授课教师允许外传的课件、PPT 、课程资料等
